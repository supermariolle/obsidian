3 banques de données ADN:

- Base de données "Condamnés": tous ceux qui ont commis des crimes
- Base de données "Traces": éléments retrouvés sur la scène de crime et dont on pense qu'ils pourraient avoir un lien avec un crime. Quand on ignore à qui/quoi elle appartient. 
- Base de données "Références": traces dont on sait qu'elles appartiennent à des personnes connues. On maitrise l'objet, on sait à qui il appartient.
- Base de données "Criminalistique": sur base de volontaire, les investigateurs (police etc) peuvent donner leur ADN.

Coupure de la carotide: pousser les doigts dedans pour bloquer le sang. Bloquer depuis l'extérieur avec la main est inutile.
