***Pourquoi l'adolescent rentre dans ces addictions?***
Cet enfant a très peu de compétences pour traiter ce pulsionnel et toutes les questions qui viennent avec la sexualisation.
Comment il va faire avec ces mouvements pulsionnels? Comment trouver en lui la maitrise nécessaire? Le travail demandé est d'abord un travail psychique. Comment traiter ce tsunami? 
Pour tout adolescent, il y a une demande. Les repères internes sont-ils suffisants pour pouvoir traiter ce qui arrive au corps? 
Certains adolescents n'arrivent pas à intégrer, élaborer, traiter psychiquement ce qu'il se passe. 
Le contenu vient s'imposer pour colmater quelque chose, une faille déjà présente, un trouble, une excitation non maitrisée qui est ce mécanisme de l'addiction. 
Il n'y a rien qui assouplit, qui apaise. On est dans du contenu littéral, explicite. 
Impossibilité pour ces ados de se créer des digues internes qui créeraient ces fissures.


Isolement, désir d'être accepté, facteurs numériques (accessibilité), vision centrée sur les actes, la performance. A aggravé la faible estime d'eux-mêmes. 

sublimation, impulsions scopiques (oeil comme zone érogène), le *contenu est partiel* dans le sens de la fixation sur un genou, une jambe, l'acte cru. L'acte sexuel démontré n'est que partiel. La relation intégrée, la rencontre, l'amour est exclu. Ce qu'on entend dans l'addiction est que l'adolescent n'a pas eu de réponse à ces questions relationnelles.
