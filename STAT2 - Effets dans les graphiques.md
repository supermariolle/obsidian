**==Effet simples==**
Effet Simple
Un **effet simple** est l'effet d'une variable **à un niveau spécifique d'une autre variable**. C'est une comparaison "locale".
Ex: 
- **L'effet de la taille du contenant pour les femmes uniquement.**
- **L'effet du sexe pour la taille de contenant "Grande".**
JE choisis une variable, par exemple la variable genre, je fais donc 2 effets (M/F) puis je regarde ce qui reste, ici, je check le traitement à travers le temps.
