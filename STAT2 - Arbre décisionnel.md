VD métrique normalement distribuée?

==Données normalement distribuées:==

|                         | 1 VI                             | Plusieurs VI                     |
| ----------------------- | -------------------------------- | -------------------------------- |
| VI inter sujets         | Anova 1 Chapitre 2               | Anova factorielle Chapitre 4     |
| VI intra-sujets         | Anova mesure répétées Chapitre 5 | Anova mesure répétées Chapitre 5 |
| VI inter + intra-sujets | /                                | Anova mixte Chapitre 6           |
=> intra-sujet = mesure répétées
=> inter-sujets = Anova 1 ou analyse factorielle
=> inter + intra = Anova mixte

==Pas de normalité?==

|                         | 1 VI                       | Plusieurs VI |
| ----------------------- | -------------------------- | ------------ |
| VI inter sujets         | Anova 1 Kruskall-Wallis    | /            |
| VI intra-sujets         | Test des rangs de Friedman | /            |
| VI inter + intra-sujets | /                          | /            |

On peut ensuite être questionné sur les effets simples et les comparaisons multiples. Dans le cas des Anova mixtes, il faut choisir correctement les 2 carrés-moyen erreur pour les effets simples et comparaisons multiples.

**Coefficient de correlation**
1) Données brutes ou rangs (ou problèmes de normalité)?
2) Plusieurs VI? 

==Coefficient classique de Pearson==
Si on a des données brutes normalement distribuées et 1 VI: Coefficient de corrélation classique de Pearson. 

Cas particulier: corrléation bisériale de points: une ou 2 des vraiables sont dichotomiques sont nominales - on remplace les valeurs dichotomiques avec des 0 et des 1 pour travailler sur les valeurs

==Corrélation partielle==
\> 2 VI

==Données en rangs? ==
1, 2, 3, 4, ... 10 etc. Ou problème de normalité qui nous a demandé de convertir en rangs. Spearman est une corrélation non paramétrique, donc pour des données non distribuées. 
Si plus de 2 classements (plus que 2 juges pour classer les mêmes choses), **coefficient de concordance de Kendall**.
